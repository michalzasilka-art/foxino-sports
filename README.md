# Foxino Sports

A fugio.co game: https://www.fugio.co/sports/ (phones: https://www.fugio.co/sports/play · Foxino Tennis: https://www.fugio.co/sports/tennis/)

This repo is a copy of the game exactly as it is published on fugio.co. It is a static web game (HTML + JavaScript,
no build step): the files are served from the site's `sports/` folder and use the shared `shared/` scripts.

Every publish of the game is one commit with a version tag: v001, v002, v003, ...
